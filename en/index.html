Questions

Frequently asked questions

How much does it cost?

You try it free for 14 days. Then you need a license: €4.99 a month or €39 once, forever (Plus: €9.99 or €79). The models run on your PC, so you pay no tokens. All the details are on the pricing page.

Do I need internet?

Only to download Ollama and the models the first time. After that it works offline. When you're online it can also search the web for documentation.

What's the difference between the zip and Studio?

The zip gives you MyDevAgent in the terminal, for Windows, Linux and macOS. Studio is a full editor for Windows with Vio in the sidebar, and it installs Python, Ollama and MyDevAgent by itself.

Can it mess up my files?

In ask mode it asks you before every change and shows you the diff. If you don't like something, /undo takes you back. In plan mode it only reads.

Does it work with Claude Code plugins?

Yes: plugins, skills, hooks, subagents and MCP servers in the same format as Claude Code. Install them with /plugin install.

Is there an Italian version?

Yes: MyDevAgent was born in Italian. The Italian site downloads the Italian edition; this page downloads the English edition (branch EN-MyDevAgent).

What is MyCode?

It's our own AI model for code, trained specifically for MyDevAgent and designed for an 8 GB GPU. It's still in training.

Something isn't working?

See troubleshooting: it has fixes for the most common cases. In the terminal, /doctor checks everything and tells you what to fix.
